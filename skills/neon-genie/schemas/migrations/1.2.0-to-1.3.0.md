# Opportunity and commercial packets 1.2.0 → 1.3.0

Additive. A packet with `schema_version` below 1.3.0 still validates.

## What 1.3.0 adds

Packaging recomputes each `kill_criteria` threshold when `schema_version` is
1.3.0 or newer. The optional `derivation` object carries:

- `formula` — `identity`, `sum`, `min`, `product`, `net_of_percent_and_fixed`,
  or `min_tier_net_of_fee`
- `inputs` — the numbers the formula uses
- `depends_on` — costs that must be present in `inputs` (for a fee-net tier
  kill: `every_tier`, `stripe_percent`, `stripe_fixed`)

`min_tier_net_of_fee` also needs `inputs.tier_count` equal to the length of
`inputs.tiers`. A missing input fails (NG-KILL-005). A threshold that is not
the recomputed value fails (NG-KILL-004).

These checks are not in the JSON Schema `required` array. A 1.2.0 packet that
omits `derivation` still validates.

## Labels

An OBSERVED date that is a sentinel (`1970-01-01` and the other sentinels in
`packet_compose.date_is_placeholder`) or that says placeholder / TBD fails
(NG-LABEL-001) at any schema version. A cited `quote` that does not support
the claim fails (NG-LABEL-002). Support the checker cannot decide fails closed
unless a pluggable quote judge returns `supports` (NG-LABEL-003).

## Not a break

1.1.0 and 1.2.0 packets remain valid. Prose `kill_criteria` still fails at
every version when the field is present.
