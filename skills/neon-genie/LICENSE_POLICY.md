# Zero State licensing policy

This repository now uses the **MIT License** for original Zero State materials.
See [`LICENSE`](LICENSE).

This change applies **going forward**. It does not rewrite earlier license
grants in repository history, forks, or downloaded copies. Third-party
components remain governed by their own valid licenses. Do not remove or
replace third-party notices.

## Scope

The MIT License applies to Zero State-owned source code, documentation,
designs, prompts, workflows, schemas, configuration, and other original
materials in this repository.

## SPDX identification

For new Zero State-owned source files, use:

```text
SPDX-License-Identifier: MIT
```

Do not apply this identifier to third-party files that already have their own
licenses.

## Contributions

Only authorized Zero State contributors and agents may submit changes unless
Zero State has approved a separate written agreement. Zero State may require a
contributor license agreement, intellectual-property assignment, work-for-hire
agreement, or other written agreement before accepting an external
contribution.

This relicensing is made through a reviewable pull request. Existing license
grants in repository history, forks, or third-party components are not
rewritten by this change.
