# Opportunity and commercial packets 1.1.0 → 1.2.0

Schema files stay at `schemas/opportunity-packet.schema.json` and
`schemas/commercial-simulation.schema.json`. The document `$id` is 1.2.0.
The `required` array did not grow, so packets that omit `schema_version`
or set it below `1.2.0` still validate.

## What 1.2.0 adds

Packaging (`scripts/validate_packet.py`, `scripts/packet_compose.py`)
requires these fields only when `schema_version` is `1.2.0` or newer:

| Field | Rule |
|---|---|
| `research` | Gathering record. Offline / disabled runs have no OBSERVED claims. An OBSERVED claim needs an http(s) URL and `retrieved_at` (`YYYY-MM-DD`). |
| `input_contradictions` | `checked: true` and a `findings` list. Empty is valid. Kinds: `contradiction`, `arithmetic_error`, `inconsistent_figure`. |
| `kill_criteria` | Non-empty list. Each item: `metric`, numeric `threshold`, `comparison` (`lt` `lte` `gt` `gte` `eq` `neq`), `check_date`, `data_source`, `claim_label`. A string fails (NG-KILL-001) at any schema version if the field is present. `OBSERVED` needs `evidence_refs`. |
| `build_handoff.first_commit` | `touch` (one or more areas), `done_when`, `test_to_write`, `owner_role`. |
| `page_budget` | Decision prose ≤ 450 words and ≤ 3200 characters. `truncated` is false. Long evidence is in `appendix` in full. |
| `appendix` | `research_claims` and `contradiction_evidence`. Not part of the one-page count. |

## How to migrate a 1.1.0 packet

1. Set `schema_version` to `1.2.0`.
2. Run the input-note pass and store the result, even when `findings` is empty.
3. Replace any prose kill with one structured criterion. If the number is a proposed test design, label it `SPECULATIVE` or `INFERRED`. Do not label a price `OBSERVED` without a source.
4. Add `build_handoff.first_commit`.
5. Set `research` to the offline record when no fetch ran:

```json
{
  "enabled": false,
  "offline": true,
  "adapter": "null",
  "research_ran": false,
  "items": [],
  "observed_claims": [],
  "rejected": []
}
```

6. Let `scripts/packet_compose.py` set `page_budget`. Do not shorten strings to fit.

`scripts/packet_compose.attach_offline` does steps 2–6 for a packaging recipe without calling an adapter.
